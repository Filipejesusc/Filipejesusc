## 🚀 Projeto em destaque

## 📦 VendaFácil

Aplicativo Android desenvolvido como projeto acadêmico com o objetivo de auxiliar pequenos comerciantes no controle de estoque e gerenciamento de produtos.

O projeto busca substituir controles manuais, reduzindo erros de cadastro, facilitando consultas e melhorando a organização das informações.

### Funcionalidades:
✅ Cadastro de produtos  
✅ Listagem de estoque  
✅ Pesquisa de produtos  
✅ Edição de informações  
✅ Exclusão com confirmação  
✅ Validação de dados  
✅ Integração com Firebase Firestore  

### Tecnologias utilizadas:
- Kotlin
- Jetpack Compose
- Firebase Firestore
- Android Studio
